## 1. Sistema de Design Tokens y Variables CSS (:root)

A continuación se define la estructura de variables CSS optimizada para una interfaz estilo IDE de alta densidad, organizada por jerarquía de profundidades, acentos por modalidad de agente y estados telemétricos:

  /* --- PROFUNDIDAD Y SUPERFICIES (Dark Obsidian Theme) --- */

  --bg-panel-base: #111115;       /* Fondo de paneles primarios */
  --bg-panel-header: #18181f;     /* Cabecera de pestañas y paneles */
  --bg-card-hover: #22222c;       /* Tarjetas e ítems al pasar el cursor */
  --bg-input-active: #0d0d11;      /* Inputs de prompt y editores */

  /* --- BORDES Y SEPARADORES --- */
  --border-subtle: #1f1f2a;       /* Divisiones estándar entre paneles */
  --border-muted: #2e2e3d;        /* Bordes de inputs y contenedores */
  --border-active: #6366f1;       /* Panel con foco / seleccionado */

  /* --- PALETA POR MODALIDAD DE AGENTE --- */
  --agent-video-accent: #a855f7;  /* Violeta Neón (Visión y Video) */
  --agent-video-glow: rgba(168, 85, 247, 0.25);
  
  --agent-audio-accent: #06b6d4;  /* Cian Neón (Audio, DSP y Música) */

## 2. Estilos y Estéticas Alternativas de Tema

### A. Dark Obsidian / Glassmorphism Hybrid (Predeterminado)

* **Estética:** Fondos en negro profundo (`#08080a`) con paneles en acrílico semitransparente, desfoque de fondo (`backdrop-filter: blur(12px)`) y bordes refinados de `1px`.
* **Ideal para:** Trabajo prolongado nocturno, concentración y resaltado de código/formas de onda de audio.

```css
.panel-obsidian {
  background: rgba(17, 17, 21, 0.75);
  backdrop-filter: blur(16px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.07);
  box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.37);
}

```

### B. Cyber-Tactical / Matrix High Contrast

* **Estética:** Sin transparencias. Negros puros (`#000000`), fuentes monoespaciadas rígidas, rejillas secundarias visibles (`grid pattern background`), y micro-indicadores tipo terminal o instrumental de aviación.
* **Ideal para:** Telemetría intensiva, inspección de código y depuración de modelos en vivo.

```css
.panel-tactical {
  background: #050505;
  border: 1px solid #1a2332;
  background-image: radial-gradient(#1e293b 1px, transparent 0);
  background-size: 16px 16px;
}

```

### C. Minimal Studio Light (Modo Claro de Alto Rendimiento)

* **Estética:** Tonos blanco hueso (`#f8fafc`), gris zinc (`#f1f5f9`), tipografía oscura nítida y acentos saturados pero mates.
* **Ideal para:** Entornos de oficina iluminados, edición de transcripciones largas y exportación de reportes.

```css
.theme-light {
  --bg-canvas: #f8fafc;
  --bg-panel-base: #ffffff;
  --bg-panel-header: #f1f5f9;
  --border-subtle: #e2e8f0;
  --border-active: #4f46e5;
}

```

## 3. Sistema Tipográfico y Escala de Densidad

Para mantener una alta cantidad de información sin saturar visualmente la pantalla:

| Rol de UI | Fuente Recomendada | Tamaño | Peso | Interlineado |
| --- | --- | --- | --- | --- |
| **Código / Timestamps / Logs** | *JetBrains Mono / Geist Mono* | `11px` | 400 / Regular | `1.4` |
| **Cabeceras de Paneles & Tabs** | *Inter / Geist Sans* | `12px` | 600 / SemiBold | `1.2` |
| **Texto de Transcripción / Chat** | *Plus Jakarta Sans* | `13px` | 400 / Regular | `1.6` |
| **Badges / Metadatos de Agente** | *JetBrains Mono* | `9px` | 700 / Bold | `1.0` |

## 5. Micro-Interacciones de UI / UX Recomendadas

1. **Dropzone Drag Preview:** Al arrastrar un archivo de video, audio o código sobre cualquier panel, el borde del panel objetivo debe iluminarse con el color del acento de la modalidad correspondiente.
2. **Focus Mode (Double-Click Header):** Hacer doble clic en el encabezado de un panel maximiza temporalmente ese panel ocupando todo el Canvas, ocultando los demás con una animación suave de 200ms.
3. **Scrubbing Inter-Panel:** Arrastrar el cursor sobre la línea de tiempo del reproductor de video resalta simultáneamente el bloque de texto equivalente en el panel de transcripción y el pulso en la forma de onda de audio.
