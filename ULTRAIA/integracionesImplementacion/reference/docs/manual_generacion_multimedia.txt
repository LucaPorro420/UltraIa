## Módulo 2: Manual de Generación de Imágenes y Prompts (إنشاء الصور والأوامر)

### 1. Estructura Estándar de un Prompt de Imagen

Para obtener resultados de alta calidad, la formulación del *Prompt* (الأمر النصي) debe seguir esta jerarquía:


$$\text{Sujeto} + \text{Entorno/Escena} + \text{Estilo/Iluminación} + \text{Detalles de Cámara/Parámetros}$$

### 2. Ejemplos de Prompts (Traducidos y Adaptados al Árabe)

* **Concepto:** Retrato Fotorrealista Futurista
* **Prompt en Árabe (الأمر باللغة العربية):**
> "صورة فوتوغرافية سينمائية لامرأة عربية ترتدي زياً مستقبلياً، إضاءة نيون خافتة، خلفية مدينة ذكية ليلاً، عدسة 85mm، تفاصيل عالية الجودة 8k."


* **Traducción equivalente:** "Fotografía cinematográfica de una mujer árabe con atuendo futurista, iluminación tenue de neón, fondo de ciudad inteligente de noche, lente 85mm, ultra detalle 8k."


* **Concepto:** Arquitectura e Interiorismo
* **Prompt en Áرabe (الأمر باللغة العربية):**
> "تصميم داخلي لغرفة معيشة مودرن بلمسات عربية تقليدية، إضاءة شمسية طبيعية دافئة، تفاصيل خشبية ودقيقة، بدقة 4K."

## Módulo 3: Manual de Generación de Audio y Sintetización (إنشاء الصوت والتركيب الصوتي)

### 1. Clonación de Voz y TTS (توليد واستنساخ الصوت)

* **ElevenLabs / Adobe Podcast:** Permite entrenar modelos con muestras de voz de 1 a 3 minutos para generar locuciones naturales en múltiples idiomas, incluyendo dialectos árabes (الفصحى و اللهجات المحلية).
* **Música Generativa (Suno AI / Udio):** Permite ingresar letras (شعر أو كلمات) y especificar géneros musicales (ej. *Modern Arabic Pop, Instrumental Oud with Synthwave*).

### 2. Prompting para Audio y Música

* **Estructura:** `[Género musical] + [Instrumentación] + [Mood/Atmósfera] + [Tempo]`
* **Ejemplo (Árabe):**
> "موسيقى شرقية حديثة، آلة العود مع لوحة مفاتيح إلكترونية، إيقاع هادئ ومسترخي، مناسبة لفيديو وثائقي."

## Módulo 4: Generación de Video e Imagen a Video (إنشاء وتحريك الفيديو)

### 1. Técnicas de Animación (Image-to-Video / تحويل الصورة إلى فيديو)

1. **Modelos:** Runway Gen-3, Luma Dream Machine, Pixverse, Hailuo.
2. **Control de Cámara (حركة الكاميرا):**
* `Pan Right / Left` (تحريك أفقي)
* `Zoom In / Out` (تقريب / إبعاد)
* `Motion Brush` (فرشاة الحركة): Pintar áreas específicas para animar solo el agua, cabello o nubes.



### 2. Prompt de Video Cinematográfico

* **Prompt (Árabe):**
> "لقطة سينمائية بطيئة الحركة لصقر يطير فوق الكثبان الرملية في الصحراء عند غروب الشمس، حركة كاميرا سلسة، إضاءة ذهبية."


* **Traducción:** "Toma cinematográfica en cámara lenta de un halcón volando sobre dunas en el desierto al atardecer, movimiento de cámara fluido, luz dorada."

## Módulo 5: Integración y Automatización (الدمج والأتمتة عبر API)

### Arquitectura de Integración (Pipeline de AI Interconectado)

```
[Entrada de Texto / Idea] 
        │
        ▼
 [LLM (GPT-4 / Claude)] ──► Genera Guion y Prompts
        │
        ├──► [ElevenLabs / Udio] ──► Genera Audio (Voz / Música)
        │
        └──► [Midjourney / Flux] ──► Genera Imágenes
                    │
                    ▼
          [Runway / Luma AI] ──► Convierte Imagen a Video
                    │
                    ▼
          [Make / n8n Automation] ──► Publicación en Redes / API

```

### Script de Ejemplo: Integración de OpenAI API en Python

```python
import openai

openai.api_key = "TU_API_KEY"

response = openai.images.generate(
  model="dall-e-3",
  prompt="تصميم فريد لغلاف كتاب عن الذكاء الاصطناعي والمستقبل، بأسلوب فني حديث",
  n=1,
  size="1024x1024"
)

image_url = response.data[0].url
print("URL de la imagen generada:", image_url)

```

## Módulo 6: Roadmap y Buenas Prácticas (خارطة الطريق والممارسات الأفضل)

### Roadmap de Aprendizaje (خارطة طريق التعلم)

```
Fase 1: Fundamentos (الأساسيات)
├── Dominio de Prompts Textuales (Prompt Engineering)
└── Uso de Herramientas SaaS (Canva AI, Firefly, ChatGPT)

Fase 2: Generación Avanzada (الإنتاج المتقدم)
├── Midjourney / Flux + Parámetros Avanzados (--ar, --stylize)
└── Generación de Audio/Música (ElevenLabs, Suno)

Fase 3: Video y Edición (الفيديو والمونتاج)
├── Image-to-Video (Runway, Luma, Kling)
└── Lip-sync y Avatarización (HeyGen, D-ID)

Fase 4: Integración y Código (الدمج والبرمجة)
├── Automatización No-Code (Make, n8n)
└── Integración mediante APIs y LangChain / Python

```

### Buenas Prácticas y Ética (المشاركات الأخلاقية والممارسات الحسنة)

1. **Transparencia y Marcas de Agua (الشفافية وسلسلة النسب):** Identificar el contenido generado por IA mediante estándares como C2PA / Content Credentials.
2. **Evaluación de Sesgos (تقليل التحيز):** Revisar las respuestas e imágenes generadas para evitar sesgos culturales o de representación.
3. **Optimización de Costos de API (إدارة التكاليف):** Implementar caché en llamadas a modelos de lenguaje o imágenes para evitar solicitudes duplicadas.
