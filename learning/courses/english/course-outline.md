# English Course — UltraIa Learning

## Course Overview
This course covers English language fundamentals, technical vocabulary, and communication skills for software development and AI engineering. Designed for Spanish speakers (es/ar bilingual support).

## Level 1: Basics
- **Greetings and introductions**: Hello, Hi, Good morning/afternoon/evening
- **Personal information**: Name, nationality, contact information
- **Basic verbs**: To be, to have, to do, to want, to need
- **Question words**: What, Who, Where, When, Why, How
- **Present simple tense**: Affirmative, negative, questions

## Level 2: Technical English
- **Programming terminology**: Code, function, variable, loop, array, object, class, import, export
- **Development workflow**: Commit, push, pull, branch, merge, resolve conflicts
- **API terms**: Endpoint, request, response, status code, JSON, GET, POST, PUT, DELETE
- **Debugging**: Error, bug, fix, crash, log, output, input
- **Version control**: Repository, commit, push, pull request, main, master

## Level 3: AI/Engineering English
- **LLM/AI terms**: Prompt, token, context window, inference, training, fine-tuning, model, tokenizer
- **Development modes**: P-P (Plan), P-B (Build), L-T (Learn-Test), S-D (Spec-Design)
- **Learning concepts**: Verified truth, lessons learned, semantic memory, factual accuracy
- **Modes of operation**: Modes P-P/P-B/L-T/S-D, pivot plan/build lifecycle
- **Tools and skills**: Capability, tool, skill, agent, browser, automation

## Level 4: Bilingual Technical (es/ar)
- **Spanish technical vocabulary**: Programación, depuración, implementación, despliegue
- **Arabic technical terms**: برمجة، تصحيح، Implementación، نشر
- **Bilingual prompts**: Side-by-side es/ar technical content
- **CTA by channel**: Called-to-action in both languages for different platforms

## Course Materials
- **Vocabulary lists**: PDF/JSON format with Spanish translations
- **Practice exercises**: Translation exercises, sentence construction
- **Technical reading**: Extract from LEARNINGS.md, truth verified cases
- **Bilingual comparison**: English vs Spanish technical content

## Assessments
- **Vocabulary quiz**: 20 questions matching terms to Spanish equivalents
- **Technical translation**: Translate technical sentences from English to Spanish
- **Bilingual prompt construction**: Create prompts in both es and ar
