1.1 Gemini Omni Video Generation (motor Veo) — HUB OFICIAL DE GOOGLE
    URL: https://ai.google.dev/gemini-api/docs/video | https://deepmind.google/models/veo
    - Gemini API ofrece DOS modelos de video:
      * Gemini Omni Flash (default): multi-input (texto/imagen/audio/video),
        consistencia de personaje y edición conversacional multi-turno.
      * Veo 3.1 (veo-3.1-generate-preview / veo-3.1-fast-generate-preview):
        4K, audio nativo sincronizado, extensión de escenas, último-frame control,
        retrato 9:16 nativo y marca de agua SynthID.
    - Crear/editar videos con lenguaje natural = prompt-to-video + edición por diálogo.

1.2 CapCut AI Video Generator (Seedance 2.5) — HERRAMIENTA PROFESIONAL ONLINE
    URL: https://www.capcut.com/features/seedance-2-5-for-video-editor
    - Seedance 2.5 (ByteDance/Dreamina) live en CapCut desde el 31/07/2026:
      * Clips 4K nativos de hasta 30s en un solo pass (sin stitching).
      * Hasta 50 referencias multimodales (fotos, clips, audio, guiones, style guides, storyboards).
      * Control de movimiento R2V (green screen / white-model).
      * Audio estéreo sincronizado (SFX, música al ritmo, lip-sync).
      * Intelligent Edit Mode (edición por timestamp/región sin regenerar).
      * Modo beta Long Video de 180s. 11 idiomas. Avatares con IA y subtítulos automáticos.
    - Monetización: créditos Pro/Ultra (se cobra por segundo); créditos diarios gratis.

1.3 OpenCut (GitHub) — ALTERNATIVA OPEN SOURCE A CAPCUT
    URL: https://github.com/OpenCut-app/OpenCut  (core, en reescritura Rust)
         https://github.com/OpenCut-app/opencut-classic  (versión usable hoy)
    - MIT. Web/desktop/mobile. Clonación de voz, subtítulos automáticos, reencuadre
      (auto-reframe) por IA y text-to-video, SIN marcas de agua, gratis y local.
    - La reescritura agrega: Editor API, plugins first-class, MCP server para agentes
      AI y headless mode (automation/batch render).
    - OJO: el fork "opencut-desktop-app/opencut" (70k stars, instalador firmado) es un
      build empaquetado independiente del core oficial.

4. ALTERNATIVAS AVANZADAS DE EDICIÓN DE VIDEO POR CÓDIGO
================================================================

4.1 Remotion — VIDEOS PROGRAMANDO CON REACT
    URL: https://github.com/remotion-dev/remotion | https://remotion.dev
    - 55.7k stars. "React Code is the source of truth": render local/cliente/cloud,
      batch rendering, Remotion Player embebible, flujos agentic (coding agents).
    - ⚠ LICENCIA PROPIA (no OSI): gratis para individuos, empresas de hasta 3 empleados
      y sin fines de lucro. Company License en el resto: "for Creators" $25/seat/mes o
      "for Automators" $0.01/render con mínimo $100/mes.
    - La herramienta favorita para crear editores de video automatizados con agentes AI.

4.2 OpenShorts — VIDEOS LARGOS → CLIPS VERTICALES VIRALES AUTOMATIZADO
    URL: https://github.com/mutonby/openshorts | https://openshorts.app
    - MIT. Self-host con Docker (8GB RAM) o cloud desde $12/mo.
    - Pipeline 10 etapas: yt-dlp ingest → faster-whisper (timestamps word-level) →
      PySceneDetect → Gemini detecta 3-15 momentos virales (15-60s) → FFmpeg corta →
      reframe 9:16 (MediaPipe+YOLOv8 TRACK/GENERAL) → subtítulos/hooks → S3 → publish
      (TikTok/IG/YT).
    - Incluye MCP server (/mcp), REST API con webhooks y CLI en PyPI (openshorts).
