El desarrollo de videojuegos utilizando Inteligencia Artificial ha avanzado hasta el punto de permitir que creadores independientes, diseñadores y programadores construyan juegos completos con herramientas gratuitas. El panorama se divide entre motores nativos con IA, repositorios de código abierto y plataformas de recursos que eliminan las barreras técnicas tradicionales. [1, 2, 3] 
A continuación, se detalla el ecosistema de recursos 100% gratuitos (u opciones con planes gratuitos altamente funcionales) estructurado por áreas de desarrollo:

## ➡️ 1. Repositorios de GitHub (Código, Agentes y Curación)
GitHub aloja la infraestructura lógica, las plantillas de pensamiento de IA y los scripts necesarios para automatizar la programación de tus videojuegos. [4] 

* [simoninithomas/awesome-ai-tools-for-game-dev](https://github.com/simoninithomas/awesome-ai-tools-for-game-dev): Un directorio especializado que recopila exclusivamente herramientas de IA destinadas al desarrollo de videojuegos, cubriendo desde generación de texturas en 2D hasta mallas complejas en 3D. [5] 
* [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills): Este repositorio proporciona 67 habilidades de desarrollo de videojuegos para agentes de IA de código (como Cursor o Copilot). Detecta automáticamente si estás usando Godot, Unity, Unreal o Pygame y carga la lógica exacta para programar la tarea requerida. [4] 
* [lappemic/awesome-ai-built-games](https://github.com/lappemic/awesome-ai-built-games): Repositorio que reúne juegos comerciales y experimentales (desde Tetris 3D hasta shooters en primera persona) creados enteramente con IA. ## ➡️ 2. Motores y Plataformas de Creación Directa (No-Code & Prompt-to-Game)
Si buscas crear videojuegos directamente mediante descripciones de texto o interfaces asistidas por IA, estas herramientas ofrecen accesibilidad total:

* [Rosebud AI Game Creator](https://rosebud.ai/ai-game-creator): Una plataforma basada en navegador donde puedes describir el juego que deseas y la IA generará el código (HTML/JavaScript), los sprites en 2D, el audio e incluso mundos en 3D. Su plan gratuito te permite publicar y compartir prototipos jugables al instante. [5, 7, 8] 
* [GDevelop AI Assistant](https://gdevelop.io/): GDevelop es un motor de videojuegos en 2D y 3D de código abierto y completamente gratuito. Su sistema de eventos visuales ahora integra un asistente de IA incorporado que genera mecánicas, comportamientos y lógicas complejas sin que tengas que escribir una sola línea de código manual. [9] 
* [Summer Engine](https://www.summerengine.com/): Un motor de juego IA-nativo totalmente compatible con Godot 4. Es ideal para iniciar un proyecto 3D o multijugador a partir de descripciones de lenguaje natural y mantener el control del código de manera gratuita. [2, 8]

* Modelos de Código Local (Ollama + Gemma / Qwen): Herramientas como [Ollama](https://ollama.com/) te permiten ejecutar modelos de programación especializados de forma local en tu computadora (como Gemma o Qwen) de manera 100% gratuita, privada e ilimitada. Al conectarlos a extensiones de juego o editores, obtienes un asistente de desarrollo sin pagar suscripciones. [3, 10]

Aquí tienes los recursos clave para este flujo de trabajo profesional "Zero-Asset":
## 🏗️ Motores y Agentes para Creación Total "End-to-End"
Estos sistemas permiten que la IA genere el proyecto desde cero, incluyendo la lógica de juego y los entornos, sin necesidad de que tú aportes medios iniciales.

* Summer Engine: Diseñado específicamente para exportar proyectos reales y propios de Godot 4. Permite comprimir tu idea en una sola frase y la IA genera el bucle principal, mecánicas y arte dentro del mismo flujo.
* Claude Code Game Studios (GitHub): Este repositorio no es solo un generador de código, sino una infraestructura de 49 agentes especializados (directores, líderes y especialistas) que actúan como un estudio completo para gestionar arquitecturas complejas de videojuegos de forma persistente.
* Rosebud AI: Es una de las formas más rápidas de construir y refinar juegos reales. Su interfaz basada en navegador democratiza el código, permitiendo que la creación sea tan accesible como escribir un prompt, ideal tanto para principiantes como para estudios profesionales.
* GDevelop AI: Un motor de código abierto (2D y 3D) que utiliza un sistema de eventos único asistido por IA para construir juegos potentes sin programar. Facilita enormemente la publicación en Android, iOS y web.

## 📱 Desarrollo Multiplataforma Profesional
Para asegurar que el juego sea usable en todos los ámbitos (móvil y web) con un solo esfuerzo de creación:

* Figma AI Game Generator: Permite diseñar experiencias jugables, desde mecánicas hasta interacciones, y verlas cobrar vida sin escribir código. Es ideal para prototipar aplicaciones web y móviles de nivel MVP con modelos avanzados como GPT-5.6.
* Unity Muse: La opción estándar de la industria. Incluye un Asistente Agéntico integrado en el editor que entiende el contexto de tu proyecto, permitiendo ejecutar tareas complejas y generar escenas jugables a partir de referencias visuales o de texto.
* Replit AI Game Builder: Transforma ideas en lenguaje natural en experiencias jugables al instante dentro del navegador. Se encarga de mecánicas complejas como física, detección de colisiones y movimiento de personajes.

## 🧠 Recursos de Pensamiento y Lógica (GitHub)
Para que la IA "piense" el juego de forma profesional, puedes alimentar a tus agentes con estas bases de conocimiento:

* gamedev-skills (GitHub): Proporciona habilidades de agente para detectar automáticamente si usas Godot, Unity o Unreal y cargar la lógica exacta para programar la tarea requerida.
* awesome-game-ai: Recopila marcos de trabajo de aprendizaje por refuerzo y herramientas como Unity ML-Agents para dotar a tu juego de sistemas de inteligencia avanzados.
* Yuan-ManX/ai-game-devtools: El repositorio definitivo que centraliza herramientas de IA para cada capa: modelos de mundo, agentes, código, texturas, shaders y modelos 3D.
